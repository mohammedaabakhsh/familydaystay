# يوم العائلة

واجهة عربية لحجز الإقامة، مبنية على آخر مصدر محفوظ في Sites (الإصدار 46). هذا المستودع يحتوي على النسخة المنظفة من ملفات المشروع الحالية، دون سجل Git القديم أو ملفات التشغيل المحلية.

## التشغيل

المتطلبات: Node.js 22.13 أو أحدث، وpnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm build
```

بعد البناء يمكن تشغيل `pnpm start` لمعاينة Worker محليًا. يحتفظ المشروع بإعداد Vinext/Cloudflare الخاص به؛ نقل الملفات إلى Git وحده لا ينشر الموقع ولا ينقل بيانات خادم.

## هيكل المشروع

- `app/`: شاشات التطبيق، التصميم الحالي، الكتالوج، الخدمات، الأسعار والعروض.
- `components/ui/`: مكونات الواجهة المستخدمة فعليًا فقط.
- `public/`: الصور والخطوط والأيقونات المستخدمة.
- `lib/`: أدوات مشتركة.
- `build/` و`scripts/`: أدوات البناء والتشغيل.
- `.openai/hosting.json`: تعريف مشروع Sites الحالي وإعداد استضافته. معرّف المشروع ليس كلمة مرور أو مفتاح دخول.
- `HANDOFF.md`: وصف الحالة الحالية والبيانات ونقاط الربط المطلوبة.

## حالة التطبيق

التصفح، التفاصيل، التواريخ، اختيار الخدمات، مراجعة الاختيارات والمفضلة تعمل كواجهة. التوفر والدخول والدفع وإنشاء الحجوزات غير موصولة بخادم فعلي، وتأكيد الحجز معطل. الأسعار والعروض الموجودة جزء من آخر تصميم محفوظ، ويجب اعتمادها من خادم عند تفعيل التشغيل الفعلي.

## البيانات والخصوصية

لا توجد ملفات حسابات أو حجوزات أو مفاتيح سرية مكتشفة في المصدر بعد الفحص. الصور والمواصفات والأسعار بيانات كتالوج مقصودة وليست سجلات زوار. المتصفح يحفظ المفضلة ومسودة اختيارات لمدة 24 ساعة؛ محتويات تخزين جهاز المستخدم لا تنتقل ضمن هذا المجلد.

تستبعد `.gitignore` أسرار البيئة والملفات المحلية ونتائج البناء وقواعد البيانات المحلية. لا تضع أسرارًا في كود الواجهة؛ `.gitignore` لا يحمي قيمة مكتوبة داخل ملف مصدر متعقّب.
